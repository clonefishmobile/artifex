# 16 — Combat Rework: Slot-Based Attack System

**Ветка:** `feature/combat-rework`  
**Статус:** ТЗ  
**Дата:** 2026-05-04

---

## Суть изменения

Слот-машина переносится из фазы подготовки (lobby) в фазу боя. Каждый ход игрока начинается с кручения слотов, после чего игрок нажимает Attack и наносит урон всем выпавшим оружием.

---

## Текущий flow (до рework)

```
Backpack (lobby) → нажатие BATTLE → слот-машина крутится (3 reel) → результат → бой (пошаговый, 2 карточки атаки)
```

Слот-машина: 3 рила, `REEL_COLS=[[0,1],[2,3],[4]]` — группы столбцов бэкпака. Результат — 3 active slots. Затем пошаговый бой с выбором карточки (body part + hit chance).

## Новый flow (после rework)

```
Backpack (lobby) → нажатие BATTLE → walk → враги подходят → ПОШАГОВЫЙ БОЙ:
  ┌─ Начало хода:
  │   1. Слоты автоматически крутятся (5 рилов, по 1 на столбец бэкпака)
  │   2. Останавливаются последовательно с паузой
  │   3. Кнопка Attack становится активной
  │   4. Игрок жмёт Attack → урон врагу (суммарный по всем выпавшим)
  │   5. Ход врага → враг бьёт игрока
  │   6. Если враг жив → новый ход (goto 1)
  │   7. Если враг мёртв → wave cleared → loot → backpack
  └─ Опционально: Reroll (перекрутить слоты заново)
```

---

## Детальная спецификация

### 1. Количество слотов = количество столбцов бэкпака

- `GCOLS = 5` → **5 слотов** (вместо текущих 3 рилов)
- Каждый слот i (0..4) соответствует столбцу i бэкпака
- Слот i крутит оружие, найденное в столбце i сетки (row 0..6)
- Если в столбце нет оружия — слот всегда выпадает пустым

### 2. Содержимое рила (что крутится)

Для столбца `col`:
- Собрать все уникальные `uid` оружия, занимающие хотя бы одну ячейку в этом столбце
- Каждое уникальное оружие = один элемент рила
- **Одно и то же оружие может занимать несколько столбцов** (широкая форма) → оно будет в рилах нескольких слотов → может выпасть в нескольких слотах одновременно → **комбо**
- Пустые ячейки не добавляются в рил

Пример: Меч занимает столбцы 1-2. Рил слота 1 содержит Меч. Рил слота 2 тоже содержит Меч. Если оба выпали на Меч → комбо.

### 3. Анимация кручения

- Все 5 слотов начинают крутиться **одновременно**
- Останавливаются **последовательно** (слот 0 первый, слот 4 последний)
- Пауза между остановками: ~300-400ms
- Во время кручения — визуальная анимация (иконки оружия мелькают)
- При остановке: sfx `sfxSlotResolve()` или `sfxSlotFail()`
- Скорость кручения: быстро → замедление → стоп

### 4. Результат слота

- **Оружие выпало:** показать иконку + цвет тира
- **Пустой столбец** (нет оружия в этом столбце): показать **красный крестик ✕**
- Если одно оружие выпало в нескольких слотах → подсветить как **COMBO** (визуал доработаем позже)

### 5. UI боя (нижняя панель)

```
┌─────────────────────────────┐
│        COMBAT CANVAS        │
│       (враги, эффекты)      │
│                             │
├─────────────────────────────┤
│  [slot0] [slot1] [slot2] [slot3] [slot4]  │  ← 5 ячеек слотов
├─────────────────────────────┤
│   [ ATTACK ]    [ REROLL ]  │  ← 2 кнопки
└─────────────────────────────┘
```

- **Слоты** — горизонтальный ряд из 5 ячеек, показывают результат кручения
- **Кнопка ATTACK** — неактивна (серая) пока слоты крутятся, активна (яркая) после остановки всех 5
- **Кнопка REROLL** — активна всегда, запускает повторное кручение всех слотов
- При кручении кнопка Attack = disabled, Reroll = disabled (нельзя reroll пока крутится)

### 6. Расчёт урона

При нажатии Attack:
1. Собрать все выпавшие оружия (не-пустые слоты)
2. Для каждого оружия: `baseDmg = hero.damage * weapon.baseDmgMul * tierEffMul(weapon.tier)`
3. **Суммарный урон** = сумма урона всех выпавших оружий
4. Нанести суммарный урон текущему врагу
5. Если выпало 0 оружий (все 5 пусты) → минимальный урон кулаком (👊 Fist, damage = hero.damage * 0.5)

### 7. Комбо (задел на будущее)

Если одно и то же оружие выпало в 2+ слотах:
- Пока: просто суммируем урон нормально (каждый слот = отдельный удар)
- Позже: множитель комбо (x2 при дубле, x3 при тройке, и т.д.)
- Визуальная индикация "COMBO x2!" — реализуем позже

### 8. Reroll

- Бесплатный, без ограничений
- Нажатие → все 5 слотов начинают крутиться заново
- Та же анимация (одновременный старт, последовательная остановка)
- Можно reroll'ить бесконечно

### 9. Ход врага

После нажатия Attack:
1. Применить урон к врагу
2. Пауза ~1 сек
3. Враг атакует игрока (текущая логика `enemyTurnAttack`)
4. Пауза ~0.8 сек
5. Если враг жив → новый ход (слоты крутятся автоматически)
6. Если враг мёртв → wave cleared flow

### 10. Что НЕ меняется

- Фаза backpack (lobby) — без изменений
- Кнопка BATTLE → walk → enemies approach — без изменений
- Loot drop после волны — без изменений
- 3 волны на комнату — без изменений
- Body parts targeting (голова/тело/ноги) — **отключаем** (карточки не показываем), но **код не удаляем** (вернёмся позже)
- Звуки: переиспользуем `sfxSlotTick`, `sfxSlotResolve`, `sfxSlotFail`, `sfxHit`, `sfxMiss`
- BGM: battle music играет как раньше

## Технические заметки

### Маппинг столбцов → рил

Текущий `REEL_COLS=[[0,1],[2,3],[4]]` (3 рила, группы столбцов) заменяется на:

```js
// 5 рилов, каждый = 1 столбец
REEL_COLS = [[0], [1], [2], [3], [4]];
```

### Содержимое рила

```js
function getReelWeapons(colIdx) {
  var seen = new Set();
  var weapons = [];
  for (var r = 0; r < GROWS; r++) {
    var uid = G.grid[r * GCOLS + colIdx];
    if (uid && !seen.has(uid)) {
      seen.add(uid);
      weapons.push(G.placed.get(uid));
    }
  }
  return weapons; // может быть [] если столбец пуст
}
```

### Новый flow вызовов

```
fight начался (enemies arrived) →
  startCombatSlots()           // запустить кручение 5 слотов
    → анимация крутится
    → слоты останавливаются по очереди
    → finishCombatSlots()      // все 5 остановились
      → кнопка ATTACK активна

Игрок жмёт ATTACK →
  executeCombatAttack()        // подсчёт урона, нанесение
    → пауза 1 сек
    → enemyTurnAttack()        // ход врага (переиспользуем)
      → пауза 0.8 сек
      → endTurn()
        → если враг жив: startCombatSlots() (новый ход)
        → если враг мёртв: onWaveCleared()

Игрок жмёт REROLL →
  startCombatSlots()           // перезапуск кручения
```
